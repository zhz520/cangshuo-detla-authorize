# 0.6.4 功能商城在线购买

- 授权中心新增客户功能购买接口和一次性收款链接。
- 客户端仅提交签名实例、版本和功能编号，不提交价格。
- 订单金额、周期、生效时间和可购天数由授权中心计算并保存快照。
- 新增授权中心托管收款页，支持公众号支付、Native 和 H5 中已启用的方式。
- 电脑浏览器使用公众号支付时显示微信扫码入口，微信内打开后调起 JSAPI。
- 新增微信支付 API v3 请求签名、响应验签、通知验签和 AES-GCM 解密。
- 支付成功回调会校验商户号、AppID、订单金额和交易号，幂等确认订单并自动签发授权。
- 授权状态与客户端本地启用开关分离；授权中心不再替客户切换功能。
