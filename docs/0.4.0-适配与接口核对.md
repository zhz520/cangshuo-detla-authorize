# 0.4.0 适配与接口核对

2026-11-02。

新增手机抽屉菜单、安全区和虚拟键盘布局，优化 320px 小屏、表单输入、弹窗、长表格滚动及触摸区域；保持桌面分组菜单。构建目标覆盖 ES2018 和 Safari 13/Chrome 79 对应的 CSS 能力，网络超时使用 AbortController，避免旧内置浏览器缺少 AbortSignal.timeout 导致登录失败。

修复跨软件发布时误使用默认软件编号、无效 Release 地址返回内部错误、SMTP 传输初始化失败后重试锁不释放、缺失静态资源错误回退为 HTML 等问题。公钥交付接口不再使用预览版作为最低正式客户端版本提示。

验证包含 22 项自动化测试及完整隔离 HTTP 工作流，覆盖会话、客户、软件、项目、实例、模块、订单、授权、邮件、支付配置、正式发布和签名更新接口；错误来源、CSRF、未登录及未知接口保留拦截。

浏览器回归覆盖 PC Chromium、Android Chromium、Android 微信/QQ 用户代理、iOS WebKit、iOS 微信/QQ 用户代理及 320px 小屏，检查各菜单、客户新增/编辑弹窗、页面横向溢出与运行时异常。其中一组关闭原生 AbortSignal.timeout 验证兼容路径。

这些是浏览器引擎与尺寸/用户代理模拟测试，不等同于 iPhone、安卓或微信/QQ 的真机验收。真实 SMTP、微信支付和 GitHub 私有仓库连接使用生产已有参数另行核对，隔离测试不会创建真实收款或发送测试业务消息。

Windows 截图及本地日志放 D 盘；GitHub Actions 的 Linux 临时截图使用 runner.temp。
