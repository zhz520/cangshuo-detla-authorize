# 0.6.0 客户功能权益管理

授权运营中心新增“客户功能”页面，按客户实例管理每个付费功能的权益记录：

- 查询客户、实例、功能、开通状态、价格周期、生效时间、到期时间和剩余天数。
- 新增、编辑、启用、停用和删除功能权益。
- 客户功能页的“续费”会预填客户实例和功能并创建续费订单；完成收款和签发后才顺延权益，过期权益从当前时间重新计算。
- 同一实例和功能存在待收款、已收款未签发或维护期接入订单时不能重复下单；确认收款和签发时都会重新核对报价有效期及项目维护期，期限不足时拒绝操作，不会静默缩短。
- 未签发的待收款订单可填写原因后作废；已收款订单必须填写退款或冲正凭据后才能退款作废；维护期接入订单也可填写作废依据。作废会记录原因、原状态、退款凭据和时间，并解除重复下单阻塞。维护期接入前也会重新核对报价。
- 权益到期不能超过所属项目维护期，避免客户看到无法实际使用的期限。
- 权益保存原始到期时间，项目维护期缩短时只在许可证和客户端同步结果中临时截断；维护期恢复后，原权益期限会随之恢复。
- 每次权益变更自动更新可拉取的签名许可证和项目启用状态。许可证只包含当前有效且已启用的付费功能，停用功能从许可证撤权；项目声明继续携带停用权益的启用状态和期限映射。
- 删除最后一个权益时会保留 `core_platform` 兼容授权，同时把全部付费功能设为未启用；新旧客户端都不会因此失去核心业务。
- 订单列表按生效和到期快照计算实际新增天数，计价周期只用于说明价格对应的参考时长。

购买订单创建页会增加实时预览：价格、计价周期、生效时间、到期时间、本次新增天数和剩余总天数。订单保存价格与有效时间快照，签发时保护已存在且更长的到期日。

客户端项目声明新增 `licenseId`、`featureEnabled`、`featureStartsAt` 和 `featureExpiresAt`。项目与许可证通过同一 `licenseId` 绑定，后两者用于识别停用权益及其期限，`featureEnabled` 继续决定启用状态。许可证格式与 claims 字段保持兼容，只把有效且启用的功能放入 `features`；未购买、已停用或已过期功能不会启用。只有项目声明包含上述功能字段才启用远端托管，旧协议响应不会清除已识别的托管状态。
