# 授权中心 0.7.6 实名二要素内置适配器

日期：2026-11-17

## 新增

- 内置腾讯云 `faceid.tencentcloudapi.com` 的 `IdCardVerification` 二要素适配器，授权中心直接调用，不再要求客户自建 HTTPS 转发。
- 实现 TC3-HMAC-SHA256 签名；SecretId 明文保存便于识别，SecretKey 使用授权中心主密钥 AES-256-GCM 加密保存，接口不回显。
- 结果码映射：`0` 一致、`-1` 不一致，按次计费；`-2` 身份证非法、`-3` 姓名非法、`-4` 证件库异常、`-5` 无此身份证记录、`-6` 权威比对升级、`-7` 当日次数超限不扣费，释放预占并返回明确提示。
- 保留自定义 HTTPS 接口模式，兼容已有的 URL + Bearer Token 配置；旧记录默认按自定义模式读取。
- 数据库启动兼容新增 `provider`、`secret_id`、`secret_key_cipher`、`region` 四个可空/带默认值字段，可重复执行。

## 验证

- `npm test`：97 项通过。
- `npm run build`：通过。
- 覆盖腾讯云密钥加密、TC3 签名固定向量、结果码计费/不计费分类、非法结果释放预占和旧自定义模式兼容。
