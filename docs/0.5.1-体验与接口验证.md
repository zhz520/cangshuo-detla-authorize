风险和验证边界：

- 本轮没有使用真实 GitHub 私有仓库令牌、SMTP 或微信商户材料发起外部业务调用；验证的是本地接口连通和模拟依赖，不能据此宣称生产三方联通已验收。
- 浏览器为引擎、尺寸和用户代理模拟，包含关闭 `AbortSignal.timeout` 的兼容路径；微信/QQ 和 iOS、Android 真机仍需实际设备验收。
- 客户端上报改读本地目录，GitHub 新版本通过后台检查刷新，正常周期最长约 15 分钟；授权与维护同步不再被外部 GitHub 检查拖住。自定义入口若仅调用 `createAuthorityServer`，需自行调度检查或使用管理界面手工检查。
- 入口 JS 仍超过 Vite 默认 500 kB 提示线，保留构建提示；本轮已显著减少体积，未为消除提示而调整阈值。
- 实际安装器的服务器备份、安装、健康检查、回滚和数据库升级未执行；本轮只验证签名计划与模拟包传输，不能代替部署验收。
- 实例身份凭据不是当前电竞商城可导入的功能授权格式；交付说明已纠正，未改变客户端支持的协议。
