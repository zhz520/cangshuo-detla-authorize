# 授权中心 0.7.4 首页动画优化

- 日期：2026-11-17
- 版本：0.7.4

## 动画

- 首页标题和内容区使用轻量淡入上移动画。
- 四张统计卡按 40ms 间隔依次出现。
- 开通流程和下方三个分析卡按顺序进入。
- 授权趋势线使用路径绘制动画，数据点延迟出现。
- 授权状态圆环使用轻微缩放淡入。
- 动画只使用 transform 和 opacity，不触发布局重排。
- 切换 7/30/90 天时趋势线和数据点会重新绘制。

## 无障碍和性能

- 全面支持 prefers-reduced-motion: reduce，系统开启减少动画后会立即显示最终状态。
- 动画延迟在减少动画模式下归零。
- 图标、卡片和页面均无横向溢出。

- PC-Chrome：通过，包含动画名称、图标包含关系、页面无溢出、“立即开通”项目弹窗检查。
- Android-Chrome：通过。
- npm run build：通过。
