# 0.6.5 JSAPI 支付授权目录修复

- 公众号 OAuth 回调地址固定使用支付设置中的“授权中心支付站点 Origin”，不再由代理请求头临时推导。
- 微信内发起公众号支付时，实际调起收银台的页面为：`https://授权中心域名/api/pay/wx/oauth-callback`。
- 微信支付商户平台需要登记的实际支付目录为：`https://授权中心域名/api/pay/wx/`（必须以 `/` 结尾）。
- 管理员填写 `officialReturnOrigin` 后，后台说明会同时提示“网页授权域名”和“JSAPI 支付授权目录”两处微信配置；两项不能互相替代。
- 微信提示“当前页面的URL未注册”时，支付回调页会明确提示缺少的支付授权目录，便于运营人员核对。
