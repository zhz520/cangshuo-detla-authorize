# 授权中心 0.7.8 客户自助余额充值

日期：2026-11-17

## 新增

- 短信套餐和实名核验套餐新增「余额充值」类型：管理员设置到账金额（`credit_cents`）和售价（`price_cents`），可支持充 100 送 10 等赠送。
- 余额充值复用现有套餐支付通道（公众号 JSAPI / 微信扫码）和回调验签，不新增第二套支付逻辑。
- 套餐订单快照 `credit_cents`，支付成功后按订单快照入账；短信计入 `sms_wallets`，实名计入 `service_accounts`，同一订单重复回调只入账一次。
- 客户后台「短信服务 / 实名服务」新增「余额充值」卡片，显示到账金额和售价，点击后发起微信支付；支付完成后刷新页面即可看到余额。
- 余额充值套餐不出现在「发套餐」手动发放列表，避免运营误操作；已有购买记录时仍按原规则禁止删除。

## 验证

- `npm test`：101 项通过。
- `npm run build`：通过。
- 覆盖短信余额充值入账一次、重复回调幂等、实名余额充值入账一次、套餐订单快照和客户后台充值入口。

## 部署

- 镜像：`cangshuo-detla-authority:0.7.8`。
- 数据目录 `/opt/apps/authority/runtime` 不变；启动兼容为套餐商品和订单补充 `credit_cents` 可空/默认字段。
