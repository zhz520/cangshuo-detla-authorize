# 0.7.0 多租户服务组发布

- 发布日期：2026-11-11
- 正式版本：`0.7.0`

## 新增

- `GET /api/runtime/tenants`：运营登录后可导出带显式 `runtimeTenantId`、实例 UUID、服务组和域名的运行时租户元数据；不返回密码、私钥、支付密钥或 Token。
- 实例新增可空 `runtimeTenantId`，全局唯一；未登记的实例不会进入运行时导出。
- 服务组、服务组成员和共享发布计划管理接口及运营后台页面。
- `cangshuo-shared-release-v1` 签名计划，校验正式版本、三个组件制品、维护窗口、启用租户、维护期和版本降级。
- 运行时租户 bootstrap 工具，采用显式映射并记录审计。

## 安全边界

- 导出、服务组和计划接口要求运营登录；写操作继续校验 CSRF。
- ed25519 签发私钥不进入浏览器，签名在授权中心完成。
- 计划不含服务器命令、任意路径、数据库凭据或支付密钥。
- 服务组管理不控制客户本地功能开关，客户业务数据仍由客户实例数据库保存。

## 验证

- Node 单元测试和 Vite 生产构建通过。
- 生产预验计划绑定 `delta-shared-prod`、三客户租户集合、`v1.12.4` 和三个制品摘要；共享执行器校验返回 `VALID`，`allow_execute=false` 时按预期阻止安装。
