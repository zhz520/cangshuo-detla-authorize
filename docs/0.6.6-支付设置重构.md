# 0.6.6 支付设置重构

- 支付配置从大型后台操作页拆分为独立的 PaymentSettings.vue，降低单文件复杂度。
- 新增系统支付能力概览：启用通道、接入项目、开放方式。
- 支付方式改为独立的卡片选择；商户参数按当前选中的支付方式动态显示，公众号支付等未启用方式不再占用表单。
- 密钥上传、回调地址、保存和项目支付接入保持原有接口与权限。
- 项目支付表支持按项目和客户搜索。
- 桌面与 Android Chrome 浏览器回归通过：登录、支付配置、草稿保留、密钥上传、回调地址、项目接入和响应式布局。
- 数据库结构和授权协议无变化。

## 授权中心整体布局

- 侧栏导航改为清晰的分组卡片，当前菜单使用高对比选中态，移动端保留抽屉式导航。
- 页面标题统一为带说明和操作的概览卡；表格工具栏、分页、状态标签和弹窗统一间距与视觉层级。
- 表格页、项目页、发布页、支付页和邮箱页共用同一套后台布局样式。
- 桌面 Chrome 与 Android Chrome 的全页面导航、弹窗、支付草稿保留、密钥上传和响应式布局回归通过。
