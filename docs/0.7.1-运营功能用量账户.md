# 授权运营中心 0.7.1

- 日期：2026-11-12
- 基线：0.7.0 共享服务组

## 新增

- 实名二要素按次计量账户、余额、冻结金额、操作流水和核验请求记录。
- 实例使用签名授权调用 /api/client/identity/verify；请求按幂等键冻结，供应商成功后扣费，失败释放。
- 并发预留串行化；超过 60 秒的遗留预留允许安全重试，避免重复供应商调用。
- 实名服务商 HTTPS HTTP 适配器，以及运营后台实名用量账户页面。
- 柔光拟态主题草稿商品，供客户端 1.14.0 主题商店使用；价格和上架仍由运营设置。
