# 授权中心 0.7.5 短信与实名配置修复

日期：2026-11-17

## 修复

- 短信模板编辑回填 `template_key`、`sign_name`、`provider_template_code`、`billing_units` 等字段，避免编辑后写成 `undefined` 模板键。
- 短信套餐和实名套餐的新增/编辑表单按后端字段回填，新增时清空旧 `id`，避免把新增误当成编辑或触发唯一键冲突。
- 模板、短信套餐、实名套餐补齐删除入口；有发送、购买或发放记录时后端拒绝删除并提示改为停用。
- 唯一键冲突返回具体字段提示，不再统一显示“编号已存在或关联信息不正确”。
- 「初始化验证码模板」一次创建 `otp_login`、`otp_reset`、`otp_bind_old`、`otp_bind_new`、`otp_wechat_bind`；已有启用模板时复制其签名、阿里云模板 Code 和变量，创建后即可被 520 识别。
- 实名供应商配置增加接口约定说明：`POST {"name","idNumber"}`、`Authorization: Bearer`、返回 `{"matched","requestId"}`。
- 短信模板最低客户端版本默认值改为 520 当前基线 `1.16.5`。

- `npm test`：93 项通过。
