# 授权中心 0.7.9 短信版本门槛与预占安全

## 范围

- 短信发送按模板 min_client_version 校验客户版本；缺失、格式错误或低于门槛时，不预占额度、不调用阿里云。
- 相同幂等键的重复发送仍返回原请求，不重复预占、发送或计费。
- 实名手工充值按实例 + 非空引用幂等；相同引用不同金额拒绝。
- 实名 RESERVED 请求支持人工释放：只释放预占，不扣余额、不自动重试供应商；重复释放幂等并写审计。
- 管理后台「实名核验服务账户」可释放单条预占，也可按实例释放超过 10 分钟的陈旧预占。

## 行为边界

- 短信版本比较使用数字段比较，不使用字符串字典序；模板保存也校验 x.y.z 格式。
- 释放阈值最低 60 秒，避免与仍在进行的供应商调用竞争。
- 本次没有修改真实供应商、支付回调或客户数据，也没有把内存 SQLite 测试当作生产验收。
