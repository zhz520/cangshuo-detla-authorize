# 0.6.1 微信公众号支付能力

- 微信支付通道新增 `OFFICIAL`（公众号支付）能力，与小程序 `JSAPI`、微信外 `H5`、`NATIVE` 和 `APP` 分开维护。
- 支付设置新增公众号 AppID、公众号 AppSecret、公众号支付站点 Origin；选择公众号支付前会校验这三项配置。
- 公众号站点 Origin 只接受不含路径、查询参数和锚点的 HTTPS 地址。
- 项目设置可选择公众号支付作为项目实际开放方式；实例同步只下发通道和方式名称，不下发 AppSecret 或商户密钥。
- 客户端的公众号支付实现、网页授权、OpenID 获取和微信平台配置步骤，见客户端仓库的《1.4.4 微信公众号支付配置教程》和《微信支付商户平台配置教程》。
