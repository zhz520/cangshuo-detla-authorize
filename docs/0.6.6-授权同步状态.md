# 授权中心与客户系统同步状态

## 实时链路

- 微信支付回调验签成功后，订单、权益和签名授权在同一个服务端事务中完成，不需要客户后台再次付款。
- 授权中心后台保存客户、项目、功能权益和价格后立即写入本地数据库；同一后台页面刷新后读取新数据。
- 在线客服使用 WebSocket 推送，新消息和会话状态不需要轮询等待页面刷新。

## 按周期或手动同步

- 客户系统向授权中心上报版本和读取授权快照，默认间隔 300 秒，可通过客户系统的 platform.report.interval-ms 配置。功能商城还支持即时“同步授权”，支付返回时自动同步一次。
- 权益有效期、功能模块目录和更新目录在客户下一次成功上报后生效。权限撤销和到期不会依赖 WebSocket 推送。
- 客户系统实际启用的功能由客户管理员在本地决定；授权中心改变的是授权是否有效。
- 授权中心检查 GitHub 正式版默认每 15 分钟一次，也可以手动检查。
- 邮件队列每 60 秒处理，失败按策略重试。

## 价格与订单规则

- 商城展示价来自最近一次授权快照，允许短时间滞后；支付页金额始终由授权中心按当前模块报价生成。
- 价格、授权周期、上架状态或最低客户端版本改变时，已存在的未支付订单立即作废，旧的支付链接不能继续付款。
- 已支付但尚未签发的订单保留，防止客户付款后因改价失去授权。
