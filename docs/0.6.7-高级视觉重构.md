# 0.6.7 高级视觉重构

- 授权中心统一为深色品牌侧栏、半透明吸顶工具栏、深蓝页面主视觉和浅色工作区。
- 统计卡片、表格、搜索栏、输入框、按钮、标签、分页和弹窗统一使用精细边框、克制的阴影和一致圆角。
- 导航分组增加清晰层级，当前菜单具有高对比指示和柔和光效。
- 登录页改为品牌深色背景与高质感登录卡片。
- 桌面和移动端分别优化内容密度、表单两列布局、操作按钮和安全区域。
- 保留所有现有的客户、项目、授权、订单、支付、邮件、发布和在线客服功能。
- 桌面 Chrome 与 Android Chrome 全流程浏览器回归通过，包含支付草稿保留、密钥上传、表格筛选、弹窗和响应式无横向溢出。
- 数据库结构和接口协议无变化。
