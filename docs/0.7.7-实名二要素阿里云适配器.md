# 授权中心 0.7.7 阿里云实名二要素适配器

日期：2026-11-17

## 新增

- 内置阿里云 `cloudauth.aliyuncs.com` 的 `Id2MetaVerify` 二要素适配器，授权中心直接调用，不需要客户自建转发服务。
- 实现阿里云 RPC HMAC-SHA1 签名；AccessKey Secret 使用授权中心主密钥 AES-256-GCM 加密保存，接口不回显。
- 阿里云模式为默认推荐；保留腾讯云 `IdCardVerification` 和自定义 HTTPS 接口，已有配置不受影响。
- 阿里云和腾讯云的 AccessKey/Secret 分别加密保存；切换服务商不会覆盖另一家，切回后可直接启用。
- 结果码映射：`Code=200` 且 `ResultObject.BizCode=1` 一致、`2` 不一致，按次计费；`3` 无记录、接口异常、AccessKey 或权限错误不扣费，释放预占并返回明确提示。
- 官方后付费价格：身份二要素核验 0.2 元/次；预付费 500 次 98 元、1 千次 190 元、2 千次 368 元、5 千次 900 元、1 万次 1,700 元、5 万次 8,000 元、10 万次 15,000 元、50 万次 70,000 元、100 万次 130,000 元。
