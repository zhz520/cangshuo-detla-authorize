# 授权中心 0.7.3 首页 UI 热修复

- 日期：2026-11-17
- 版本：0.7.3

## 修复

- 刷新期间不再显示旧的深色启动页，改为浅灰背景和深色加载环。
- 修正统计卡图标被旧样式强制为块级元素导致的位置偏移和裁切。
- 统一统计卡图标与箭头的尺寸、颜色和垂直居中。
- 将“已签发授权”图标改为更清晰的勾选图标。
- 修复首页装饰背景造成的横向页面溢出。
- 修复“立即开通”点击后没有内容的问题：现在会切换到项目管理并直接打开新增项目弹窗；没有客户时先打开新增客户。

## 验证

- `npm test`：75/75 通过。
- `PC-Chrome`：通过，包含图标包含关系、页面无横向溢出、“立即开通”打开项目弹窗。
- `Android-Chrome`：通过。
- `npm run build`：通过。
- 未修改后端接口、权限规则和业务数据结构。
