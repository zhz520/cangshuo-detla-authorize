# 微信支付配置说明

## 支付回调地址是什么

支付回调地址（Notify URL）是微信服务器在客户购买付费功能后主动访问的授权中心地址。它必须能从公网访问，并由授权运营中心处理。

当前 742 客户的功能购买款进入授权中心，填写：

```text
支付回调：https://auth.kk520yy.com/api/pay/wx/notify
退款回调：https://auth.kk520yy.com/api/pay/wx/refund-notify
```

回调域名固定为授权运营中心，路径不能变。不能填写 `localhost`、`127.0.0.1`、内网 IP 或客户端自己的域名。

客户端只发起购买请求并跳转到授权中心收款页，不会收到商户号、API v3 密钥、公众号 AppSecret 或证书。支付结果由授权中心验签、核对金额并自动开通功能。

## 两个文件怎么上传

在“支付设置 → 微信支付”中点击对应字段右侧的“上传文件”：

- 商户私钥文件上传微信支付商户平台下载的 `apiclient_key.pem`。
- 微信支付公钥文件上传当前商户号在微信支付平台下载的 `pub_key.pem`。

系统会校验证书内容，最多接受 32KB，只接受 PEM、KEY 或 TXT 文件。上传成功后会自动填写服务器受保护路径；随后仍需点击“保存支付通道”完成配置。

## 商户参数对应关系

- 微信支付商户号：商户平台的商户编号。
- API v3 密钥：商户平台 API 安全中设置的 32 字节密钥。
- 商户证书序列号：与上传的商户私钥配套的证书序列号。
- 微信支付公钥 ID：微信支付平台公钥页面显示的 `PUB_KEY_ID_...`。
- 微信应用 AppID：H5、小程序、Native 或 App 支付使用。
- 公众号支付 AppID / AppSecret / 站点 Origin：只用于公众号支付，必须填写独立的公众号参数。

公众号支付站点 Origin 填授权中心公开地址，例如 `https://auth.kk520yy.com`，只填写协议和域名，不带路径。它与支付回调地址是两项不同配置。

授权中心同时兼容微信支付公钥模式与微信支付平台证书模式。首次连接微信支付 API 时会通过已认证的 HTTPS 请求读取并验证平台证书，之后按微信返回的证书序列号自动选择验签公钥。商户私钥只用于发起请求和 JSAPI 支付签名。

## 保存前检查

1. 回调地址可被公网 HTTPS 直接访问，路由与上面固定路径一致。
2. 商户私钥与证书序列号属于同一套商户材料。
3. API v3 密钥为 32 字节。
4. 微信支付公钥 ID 与上传的公钥文件对应。
5. 公众号支付使用公众号自己的 AppID、AppSecret 和站点 Origin。
6. 支付通道和项目都要勾选「公众号支付」。只开公众号支付也能购买短信和实名套餐，不要求开通 Native。公众号网页授权域名为授权中心域名，微信商户平台 JSAPI 支付授权目录为 `https://授权中心域名/api/pay/wx/`。

## P0 固定规则：公众号支付按终端展示

- 新收款页（功能、主题、短信套餐、实名套餐）：手机微信直接进入授权并拉起 JSAPI；电脑微信及其他手机、电脑浏览器显示收款页二维码，由手机微信扫描。不以是否启用 Native 作为生成二维码的前置条件。
- 公众号支付未开启时，仍使用项目原有可用的付款通道。已有支付单保持原通道；不因切换设备重开另一通道的支付单。
- 前端返回只显示「正在确认」，以微信验签回调为准进行签发、发放，重复通知不能重复处理。
- 该规则必须覆盖移动微信、桌面微信、普通浏览器、扫码和支付确认回归，未经用户明确要求不得更改。

实名套餐为支付单新增可空 `openid` 字段，启动时兼容补列。已有 Native 支付单无需回填。回滚到旧代码会暂不识别新创建的公众号套餐收款流程；应保留数据库和回调处理，先核对或等候在途订单完成，不删除列或恢复老库覆盖已付款记录。
