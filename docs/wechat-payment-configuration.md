# 微信支付配置说明

## 支付回调地址是什么

支付回调地址（Notify URL）是微信服务器在用户支付完成后主动访问的客户端后端地址。它必须能从公网访问，并且由客户端电竞系统处理，不是授权运营中心地址。

当前 742 客户端填写：

```text
支付回调：https://jgsapi.kk520yy.com/api/pay/wx/notify
退款回调：https://jgsapi.kk520yy.com/api/pay/wx/refund-notify
```

其他客户须把域名换成自己的客户端公网 API 域名，路径不能变。不能填写 `localhost`、`127.0.0.1`、内网 IP、授权中心域名或需要登录后才能访问的页面。

## 两个文件怎么上传

在“支付设置 → 微信支付”中点击对应字段右侧的“上传文件”：

- 商户私钥文件上传微信支付商户平台下载的 `apiclient_key.pem`。
- 微信支付公钥文件上传当前商户号在微信支付平台下载的 `pub_key.pem`。

系统会校验证书内容，最多接受 32KB，只接受 PEM、KEY 或 TXT 文件。上传成功后会自动填写服务器受保护路径；随后仍需点击“保存支付通道”完成配置。

## 商户参数对应关系

- 微信支付商户号：商户平台的商户编号。
- API v3 密钥：商户平台 API 安全中设置的 32 字节密钥。
- 商户证书序列号：与上传的商户私钥配套的证书序列号。
- 微信支付公钥 ID：微信支付平台公钥页面显示的 `PUB_KEY_ID_...`。
- 微信应用 AppID：H5、小程序、Native 或 App 支付使用。
- 公众号支付 AppID / AppSecret / 站点 Origin：只用于公众号支付，必须填写独立的公众号参数。

公众号支付站点 Origin 填客户端页面来源，例如 `https://jgs.kk520yy.com`，只填写协议和域名，不带路径。它与支付回调地址是两项不同配置。

## 保存前检查

1. 回调地址可被公网 HTTPS 直接访问，路由与上面固定路径一致。
2. 商户私钥与证书序列号属于同一套商户材料。
3. API v3 密钥为 32 字节。
4. 微信支付公钥 ID 与上传的公钥文件对应。
5. 公众号支付使用公众号自己的 AppID、AppSecret 和站点 Origin。
6. 项目开放哪些支付方式由项目管理单独选择；系统不会按浏览器类型自动切换。
