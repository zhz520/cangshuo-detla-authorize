# 授权中心 0.7.2 UI/UX 深度重构发布记录

- 日期：2026-11-17（Asia/Shanghai）
- 项目：`cangshuo-detla-authorize`
- 版本：0.7.2
- 范围：授权中心前端 UI/UX、登录页、侧边栏信息架构、运营概览、业务列表/配置页面、移动端布局和统一交互样式。
- 边界：未修改既有 API、权限规则、业务状态流、数据库结构和真实数据结构。

## 设计结果

- 全局改为黑、白、银灰设计体系，主操作按钮和菜单选中状态使用深色，不使用大面积蓝色或高饱和渐变。
- 左侧导航按工作台、客户与业务、产品与授权、账户与结算、发布与设置重新分组；在线客服固定在底部快捷区，侧边栏支持独立滚动、折叠和图标 Tooltip。
- 登录页采用黑白银灰弧形背景、白色悬浮登录卡片、账号/密码线性图标、记住登录账号和密码重置指引。
- 运营概览增加趋势图、权益状态分布和最近操作摘要；图表全部基于现有授权/权益数据计算。
- 业务页面统一为页面标题、指标摘要、工具操作区、搜索、表格/移动卡片和分页结构。
- 编辑弹窗、抽屉、表单、Toast、Loading、骨架屏和空状态统一为同一套视觉和交互规范。
- 移动端列表改为信息卡片，不依赖横向拖动才能访问操作；登录页切换为单栏布局。

## 菜单功能覆盖

工作台、客户管理、项目管理、实例接入、软件中心、功能与定价、客户功能、实名用量账户、购买订单、授权管理、版本发布、服务组发布、支付设置、邮件通知、操作记录、在线客服均保留原入口和原页面行为。
