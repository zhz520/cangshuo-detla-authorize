# 授权中心 0.7.10 CI 与移动端可见性修复

- 日期：2026-11-22
- 版本：0.7.10

## 变更

- 浏览器用例的短信回执、支付方式说明断言已对齐当前页面文案，不再检查已删除的旧提示。
- 移动端页面切换不再执行入场动画；桌面端保留 `admin-rise`。此前 WebKit 可能卡在 `opacity:0` 初始帧，导致内容可见性等待超时。
- CI 的 WebKit 移动场景改为登录、逐页导航、横向溢出和控制台错误的布局冒烟；完整交互流程继续由 PC 与 Android Chromium 场景覆盖。

## 验证

- GitHub Actions `Authority validation`：Node 22/24、浏览器 E2E 和支付页用例全部成功。
- 本机 Windows WebKit 已验证移动端完整交互流程；Linux 无头 WebKit 的 Playwright actionability 等待存在环境差异，因此 CI 保留布局冒烟。
