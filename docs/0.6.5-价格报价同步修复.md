# 0.6.5 价格报价同步修复

- 修改功能价格、授权周期、上架状态或最低客户端版本时，当前所有未支付订单立即作废，旧的支付链接会显示“订单已取消”。
- 创建支付页前再次核对模块当前价格、周期、上架状态和客户端版本。即使旧版本留下了未支付订单，也会先作废再按当前报价重新生成。
- 已支付但尚未签发的订单保持不变，避免客户已付款后因运营改价导致订单失效。
- 购买订单继续保存下单时的价格、生效时间和到期时间快照，审计记录可追溯。
- 商城展示价仍是授权快照价，页面打开、手动“同步授权”、支付返回和约每 5 分钟自动同步都会更新；实际支付金额始终以授权中心支付页为准。
- 本版本无数据库结构变更。

此修复用于避免“商城已显示新价格，但再次购买仍复用旧价格订单”的情况。
