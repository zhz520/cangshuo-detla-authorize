# 0.5.2 多收件人与通知去重

运营通知收件邮箱改为可配置多个地址。界面以标签方式录入，最多 20 个；地址不区分大小写去重，并支持通过逗号、分号或换行导入测试收件邮箱。

正式版发布通知现在对运营邮箱按“软件 + 版本”全局去重，同一版本只发送一次。每个客户项目的通知邮箱仍各自收到一条项目通知。若某个地址同时被配置为项目通知邮箱和运营通知邮箱，同一事件也只排入一封。邮件队列继续使用持久化唯一键，定时调度和状态检查重复执行不会重新入队。

升级时自动兼容原单邮箱配置，首次保存后改为数组格式；SMTP 密码与验证码保持脱敏，不写入日志。

通知邮件正文改用内嵌样式的品牌模板，包含事件标签、通知标题、清晰正文和自动通知页脚；同时保留纯文本版本。模板不加载外部图片或样式，项目名称等动态内容会经过 HTML 转义。
